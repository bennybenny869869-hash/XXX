# 录屏拆解与「留住这一刻」交互实验

## 结论及证据边界

两段参考展示同一款概念界面的不同片段。最鲜明的设计方法是：同一内容在消息、主题摘要、卡片总览之间保持可识别的身份，用连续的空间变化说明它从哪里来、回到哪里去。渐变、柔焦和圆角支持这种表达，不能单独替代它。

没有可见触点，因此不能断言采用了点击、长按、拖动或捏合。录屏无法证明首次发现性、完成效率、真实触觉或原生实现方式。第二段开头出现系统控制中心/播放器暂停，不能将其计算为应用加载时间。

| 可见时间（约） | 可见变化 | 对设计的启发 |
| --- | --- | --- |
| 第一段 1.0–3.6 秒 | 消息退入模糊背景，主题卡在前方横向移动，相邻卡露边 | 层级和相邻关系由空间说明 |
| 第一段 3.8–4.2 秒 | Bills 卡退下，消息流定位到账单相关内容并清晰 | 摘要是进入相关内容的位置线索 |
| 第一段 5.15–5.50 秒 | 整个聊天画面缩小、侧向翻转，收进总览左上 All messages 卡位 | 一次转场同时交代整体与局部的关系 |
| 第二段 3.0–3.3 秒 | Wedding toast 阅读面收回同名紫色主题卡 | 标题、颜色和原回复延续，收回后能找回对象 |
| 第二段 5.5–5.8 秒 | Running 相关内容变成蓝色摘要卡，Agent 与输入位置保持 | 任务变化时，仍保留稳定的定位参照 |
| 第二段约 6.8 秒起 | 卡片、底部主题条选中态、背景对应消息一起变化 | 多层显示同步表达同一个选择 |

审美推断：用户提供这份参考，说明“有明确意图的交互细节、内容对象的连续性、空间层次、视觉完成度”值得优先探索。这是设计假设，不能据此断言用户只喜欢紫色、渐变或卡片。

## 为什么以前三套仍然相似

前一轮共用了尚未验证的录入、复核和家长阅读结构；A/B/C 扣除导航操作均剩 48 次共同核心操作。视觉又在结构选择之后进入，最终只能改变皮肤。PRD 中的观察句、出勤规则、记录归属可以固定，页面数量、空间关系和内容出现时机仍有设计自由。

本轮不选择完整信息架构，不给方案排名，不扩展低频页面。业务顺序仍是先选观察句、再选符合的孩子，但把“归属”从暂时弹层中的选择结果变成可持续检查的画面内容。

## 可操作实验：老师的一次记录

初始模拟课堂已有 5 位孩子记录完角色呈现，陈沐言、许知夏、宋星野待记录；两位缺席不进入操作范围。数据是模拟，句子沿用现有业务资料。

- 五句可纵向扫读，“这节没观察到”作为单独的有效选项。
- 原句展开为选人空间，不把句子移到另一张无关的表单。
- 选择期间明确显示尚未保存；取消不写入。
- 保存后，姓名保留在对应句子下；未记名单同步缩短。
- 选择已属于其他句子的孩子时展示原句；保存原子改记，旧处移除、新处出现，撤销恢复原归属。
- 只提示“这一项已记齐”，不假装完成整节课或通知家长。

待验证问题：在有真实课堂记忆的情况下，这种持续可见的归属能否让老师更容易发现错记和漏记？卡片展开造成的页面移动是否可接受？这仍需要真人体验，自动化检查不能回答。

## 可操作实验：家长的一次阅读

家长只接收陈沐言本课这一方面的记录，不接收整张全班归属卡。摘要、展开、收回保持同一观察对象。当前句子随老师实际选择变化；没有记录则显示空态；没观察到不展示成长比较。历史是模拟的同作品、同方面记录。本实验没有本次目标的独立确认操作，因此不展示下一步；组件保留明确教师目标的可选显示能力，不由句子自动推断。

排印以具体表现为第一层，身份与课程作为定位，相关历史在展开后出现。用柔焦抽象形状表达气氛，不把无归属的照片冒充课堂证据。当前实验没有AI评语生成，也不调用真实发送服务。

待验证问题：家长在摘要层是否已经理解“发生了什么”？展开动作是否值得多一步？历史是否足以支撑理解，而非仅让页面更长？

## 参考中没有直接搬用的部分

- 不把教师五句必需选项藏入横滑卡组，避免多次比较时记忆相邻项。
- 不模糊掉待记录名单和已记录的归属。
- 不将手势设为唯一入口，提供明确按钮。
- 不依靠动画表达唯一状态；支持减少动态效果与无 View Transition API 的完整操作。
- 不用颜色表达能力等级，不在家长端展示内部档位与分数。

## 交付与验证范围

新实验入口为独立 `/moment/` 路径，与此前被否决的完整样例隔离。它是可操作的小范围设计探索，不是已定稿结构，也不是完整当当说产品。引用录屏仅在本地分析，不公开上传。

浏览器验证覆盖取消不写入、明确批量保存、改记/撤销一致性、刷新恢复、家长事实联动、无记录空态、未观察状态、360/390/430 像素和桌面宽度、减少动态与API降级。检查记录在本地 `reference-study/checks/result.json`。这些结果证明功能和状态一致，不证明审美偏好或真人使用效率。
