# 第二组参考与视觉修订

2026-11-05。用户反馈是“UI框架有点感觉，只有少部分样式有感觉”，不是认可上一版UI。本轮沿用可检查的记录归属关系，继续重做关键画面的视觉与状态表达，不扩展完整产品结构。

## 两组参考各自提供了什么

上一组 Agent 演示强调同一内容对象的连续性：消息、摘要与卡片总览能够相互转化，转场交代来处和去向。

本组 milo 演示强调视觉语气与明确选择：近白背景、紧排粗黑标题、集中点色、参与选中反馈的角色；不同步骤有不同的主对象（选择行、角色、表盘、首次记录的邮票）。统一来自排印与布局关系，并非把每屏做成同一种卡片。

- 新录屏1约1.6–2.6秒：数字、蓝色圆弧和端点一起改变。
- 新录屏1约8.3–8.7秒：首次记录邮票从放大倾斜状态缩小落位，随后说明与按钮出现。
- 新录屏2约3.8–4.3秒：选中行铺满紫色，文字转白，角色保留在行尾。
- 新录屏2约6.8秒起：不同角色、颜色和语气示例一起切换，主要标题与确认按钮位置稳定。

录屏没有可靠的触摸轨迹，不能断言具体手势。手机金属机框和镜头放大属于演示包装；圆形光斑可能是操作演示指示。新录屏1输入时未见键盘、计数不变，因此不能拿它证明真实输入体验或完成效率。

## 现稿的问题与这次实际修改

| 问题 | 修订 |
| --- | --- |
| 所有对象都很浅、柔和、圆，主次不坚决 | 暖纸白与近黑文字建立底层对比；紫色集中于选择；少量珊瑚印记只表示出处 |
| 教师大幅开场占位，五句重复浮卡 | 压缩开场，五句变为连续可扫读的记录行；正在编辑的一句才展开为明确的白色工作区域 |
| 选择反馈偏淡，草选与旧归属容易混淆 | 选中使用高反差紫面和勾选；状态明确区分“待保存”“原来在这里”“将改到这句”“将移回待记” |
| 家长最醒目的文字是原句的再包装 | 直接把保存的原句作为最强文字；按语义段换行，保留原文；减少重复课程信息 |
| 两边仅靠紫色相似，缺少内容关系 | 以观察、姓名、教师出处构成记录；教师是紧凑的归属列表，家长是一张可展开历史的课堂摘记 |
| 通用渐变球与课堂没有关系 | 新生成两枚折纸对话气泡对戏的原创插画，提示角色与声音；只作装饰，不代表儿童、证据或能力 |

记录规则保持：先选句再明确选人、确认才写入、取消不变、改记原子移动、撤销恢复、缺席不参与。未观察是有效记录，与未记分开。家长只看到当前孩子；没有本次教师目标确认操作，不自动补教学计划。

## 没有直接照搬的元素

不把高频五句观察改成横向角色轮播，不根据儿童表现匹配人格，不给每次保存加全屏奖励，不以邮票造型暗示能力认证。插画角色不承担教师判断。原始视频仅本地分析，没有上传到公开站点。

## 验证与仍开放的问题

最终静态文件验证批量记录、部分移除提示、改记/撤销、刷新恢复、家长原句一致、未观察与空态、窄屏和减少动态降级。390×844默认教师首屏可见五句与未观察项；这只说明当前样例布局容纳了内容，不代表真人完成更快。

界面仍是关键片段实验，不是完整产品。视觉方向是否符合用户审美、中文读感是否自然、真实课堂回忆与补漏是否轻松，均保持开放。不会把本轮完成当成用户批准设计系统或信息架构。
