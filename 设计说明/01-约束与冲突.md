# 当当说重设计：约束与冲突

本轮重新比较产品结构，不再把旧页面清单当成待施工的界面。判断依据是同一场课中的老师能否顺利留下可靠记录，以及家长能否读懂具体变化。本文件区分业务事实、待验证策略、设计自由和文档冲突；它不是已完成的测试报告。

## 1. 来源与采用顺序

| 简称 | 来源 | 本轮用途 |
|---|---|---|
| 新规则 | 00_业务规则_v1.2.md | 当前业务依据：判断 A–I、日常与历史场景、六个家长答案、状态与能力边界。 |
| 新说明 | README_先读我.md | 重设计目标、克制原则、设计自由及字典的使用边界。 |
| 旧 PRD | 00_PRD_v1.2_全量.md | 补充没有被新包取消的业务细节，并定位历史方案污染；不沿用固定页面与组件。 |
| 旧说明 | README_先读我.md | 旧包也曾明确释放结构和视觉自由，不能将历史约束误当成用户要求。 |
| 旧规范 | 统一规范_v1.2_正式版.md及旧视觉规范 | 仅用于追溯旧方案，不作为当前界面验收标准。 |
| 选项与素材 | 新包选项库、原始 Excel 和素材文件；使用边界 | 采用真实数据、选项名与现象句。忽略其中遗留的页面布局、“前端取法”和旧功能要求。 |

处理顺序：本轮用户明确要求 → 新包的具体业务规定与能力禁区 → 新包的目标和语言原则 → 旧 PRD 中未被覆盖的事实 → 设计假设。旧视觉规范中的“定稿”“必须”“照抄”不因措辞强烈而获得更高优先级。

同一份文档发生冲突时，先判断是否是不同对象或不同场景；仍有冲突则采用更具体的业务条款，并在下表保留处理理由。无法由事实支持的内容不编造。

## 2. 真正必须成立的事实

| 对象 | 不可改变的事实 | 可验证的结果 | 来源 |
|---|---|---|---|
| 角色与身份 | 本产品只面向老师、家长；教师手机号加密码登录。手机号 11 位数字、密码 6–20 位；失败保留输入，提交中不能重复。 | 不出现注册、验证码、微信教师登录、忘记密码等不存在的流程。 | 新规则:480、旧 PRD:23 |
| 课次与到课 | 一个班的一节课是一条课次。履约发生在提交记录时。签到名单只读；请假不记录、不进入完成分母、不生成报告。 | 10 人班、8 人到课时，完成分母与报告数量均是 8，绝不是 10。 | 新规则:168、491 |
| 可编辑状态 | 未开始、上课中不能记录；已下课可记录；已提交只读；撤回后保留原记录、原因与家长旧版，重新提交才更新。 | 无法绕过课程状态写入；撤回不清空草稿，不提前覆盖家长报告。 | 新规则:348、574 |
| 内容决定观察 | 基本功、发音、作品声明可观察方面；当节取并集、去重，最多 6 项。发音能查看真实拼版。 | 同时选基本功和发音时，共用的语音基础只采集一次；改内容后不漏新增观察项。 | 新规则:181、511 |
| 句子与批量记录 | 每方面五种程度的现象句，支持同程度换说法；老师先挑句子，再点所有符合的孩子；内部程度数字不外露。 | 同一句能分配多人；同人同方面不会产生相互冲突的两条当前记录。 | 新规则:196、旧 PRD:296 |
| 有效的未观察 | “这节没观察到 / 这节看不出来”表达已作判断，不能等同于遗漏，也不能充当弱档样本。 | 可完成当节记录，但不因它推出能力下降或特征确立。 | 旧 PRD:308、新规则:220 |
| 性格特点 | 六个方面中每节只看 3 个；每项三种表现加未观察；最强表现询问当时情形；不足 3 个有效样本不能确立。 | 不全测六项；不会凭一次强表现给孩子贴稳定标签。 | 新规则:218、528 |
| 家长内容 | 开头句第一人称、儿童口吻、不超过 14 字、无标点；老师的话不超过 200 字，来自人工句库与已选记录；图片可选。 | 没有素材也能提交；不会把其他孩子专属照片放进这份报告；没有证据时不写具体课堂经历。 | 新规则:231 |
| 重点观察 | 老师主动选人，必须留下具体下一次动作；不选合法；下一次带回原话。按连续次数聚合，请假不算恢复证据，摘掉需确认。 | 本次选择影响下次提醒；无动作不能提交；名单聚合不凭空新增观察。 | 新规则:251、322 |
| 接手 | 必须能读到既有课时、家庭背景、学习历史、近三次记录与特点；四件事全部确认，缺第一学习监护人则第四项锁定；14 天期限、剩余课时不超过 10 的提醒。 | 未完成不得开始第一节课；不发明教师修改家庭背景的采集流程。 | 新规则:301 |
| 跨课账本 | 日程、未完成的课、班级学员、长期历史、家长反馈与查阅都要可达；已退班记录只读。 | 克制不能以删掉低频业务为代价。 | 新规则:261、334、369 |
| 家长的六个答案 | 今天做了什么；和以前的正向变化；老师具体观察与长期特点；累计历程和每四次阶段回顾；可分享内容；对老师的反馈。 | 答案可组织在不同载体中，但不能少掉长期成长、分享或反馈。 | 新规则:387至467 |
| 评价 | 先星级后标签；4–5 星正向、3 星轻微、1–2 星负向；换星清空，最多 3 标签，选填文字不超过 50 字；同孩子同课一次。 | 低星不会只能选表扬；教师能看到反馈；预览不能代家长评价。 | 新规则:434 |
| 数据隔离与语言 | 多校区可切换且数据隔离；家长不看儿童评分、百分比、排名、内部计算术语和原始性格标签。 | 另一校区不能显示当前校区私有名单与记录；家长文案保持具体、克制。 | 新规则:475、405、608 |

三方案使用同一业务模型、同一份句子与素材库、同一组数据校验。改变的是入口和注意力的组织方式，不是放松这些事实。

## 3. 应当重新验证的策略

下列内容有设计理由，但不是已证实的业务真理。

| 策略 | 为什么值得试 | 需要什么证据 |
|---|---|---|
| 同一工作区处理全班，不逐步解锁 | 减少上下文切换，允许老师按记忆补记录。 | 老师能找到下一件未完成的事；自由切换没有增加遗漏或误选。 |
| 主要从当前教学回忆进入 | 观察项随内容出现，降低专业名词的学习成本。 | 老师能从“刚才演故事”找到该记的表现，而不是寻找菜单名。 |
| 报告草稿帮助老师判断“还缺什么” | 让记录与最终给家长的话建立直接关系。 | 不诱导老师凭成文效果选择句子；不让她逐人改写八份文章。 |
| 只有提交时集中检查完整性 | 去掉每个小步骤的“确定”与审批感。 | 未完成项易定位；老师不会临到最后才发现大量返工。 |
| 长期档案按需展开 | 不把老师暂时用不到的历史堆进课后操作。 | 接手、家长会、复盘时需要的事实仍能迅速找到。 |
| 家长先读一个真实瞬间 | 先回答“今天发生了什么”，再补充长期背景。 | 家长能复述具体行为和变化；愿意分享的原因是内容，而非只觉得图片好看。 |

“克制”本身是当前要求；“用折叠就克制了”“单屏一定更快”“更少页面一定更好”都只是可能失败的策略。来源：新说明:41、新规则:706。

## 4. 明确释放的设计自由

- 页面数量、页面名称、是否有首页、导航形式和功能组合方式可重做。新规则:16明确没有页面清单和“应该分几步”。
- 判断顺序不是强制步骤顺序；可以按回忆、待完成对象或最终内容组织。新规则:157说明编号只是索引。
- 字体、颜色、图像使用、留白、形状、动效、表现位置、相册和阅读节奏可重新设计。新说明:75明确全部开放。
- 旧“工作台四步”“每页大标题加副标题”“白卡双层阴影”“指定底部 Tab”“头像双环”“每页都要一张图片”均为旧方案，不是当前业务事实。对照旧规范:13、287、394。
- 390×844 是建议的手机检验视口，不要求把任何屏幕锁死在一个手机框里；纯静态单文件也是交付建议，不代表产品信息架构。新说明:136。

这些自由不授权增加系统不存在的能力。尤其不新增 AI 写评语、语音转文字、支付、聊天、教师数据看板、学员排名。新规则:643。

## 5. 冲突裁决与本轮约定

| 冲突 | 来源 | 本轮采用 | 对实现的影响 |
|---|---|---|---|
| 旧四步解锁 vs 新判断不等于步骤 | 旧 PRD:262、273；新规则:157 | 新包优先。取消四步审批，不取消业务依赖。 | A 可同区切换；先选句后点人、内容映射、只读出勤等持续有效。“仅提交校验”只指完整性门槛，不是任意写入无效数据。 |
| 旧教师档案雷达 vs 新禁止教师图表 | 旧 PRD:489；新规则:715 | 删除教师雷达、曲线和数据看板。 | 档案用原句和“刚来 / 现在”的事实参照；本周提交等必要事实仍保留。 |
| 全程不打字 vs 标重点必须一句动作 | 新规则:672；253 | 普通记录路径无需输入；主动标记特别事项时允许必要的一句。 | 不为达成表面“零输入”删除必填，也不伪造语音能力。可选人工动作库若使用，仍须老师明确确认其符合实际。 |
| 自由方式举例含“语音” vs 能力禁区 | 新说明:76；新规则:654 | 能力边界优先。 | 三方案不做语音转文字记录。录音素材可上传，与语音识别是不同功能。 |
| “攒够三次同样” vs 明确统计判定 | 新规则:222；534 | 具体计算条款优先：有效样本少于 3 不确立；达到 3 后按出现比例判断。60% 先匹配“≥60% 确立”，倾向区间取不足 60%。 | 未观察不充当弱档样本；不把本节最强表现直接翻译成稳定特点。比例和阈值不显示给家长。 |
| 开头句示例超长且有标点 vs 明确长度规则 | 新规则:235、236 | 长度、儿童口吻和无标点规则优先；示例不是合法样本保证。 | 对真实选择库逐条检查，超限示例不直接进入可选项。 |
| 老师的话可空 vs 新要求每人有一段 | 旧 PRD:522；新规则:237 | 新要求优先；提供来自已选事实和人工模板的初稿。 | C 在未选观察前仅显示待补证据，不先编写孩子的经历。无素材不会导致初稿缺失。 |
| 家长只出现两类数字 vs 星级与阶段不足次数 | 新规则:612、436、423 | 儿童能力不数字化；反馈保留五颗星与中文满意程度。阶段不足保留明确的剩余记录次数，作为具体业务条款的窄例外，不扩展成评分。 | 不用“换成中文数字”掩盖同一含义；不由此放行百分比、雷达刻度、能力排名。该解释保留在交付中供产品复核。 |
| 家庭本期不采集 vs 接手必须看家庭背景 | 新规则:301、536 | 区分既有家庭资料与四轴评价采集。 | 可读取地址、职业、监护人和兄弟姐妹；不新增家庭支持等四轴表单。缺监护人时保留阻断和补资料路径说明。 |
| 学员级别/班级容差 vs 禁学员 L 体系 | 新规则:285、509、656 | 保留班型、阶段和已有教务字段，不另造 K12 式学员 L 分级。 | 不按 L 级别锁内容库，不凭空提供升级或分班决策。 |
| 概述“四个答案” vs 正文六项 | 新说明:32、63；新规则:387 | 按完整第四章覆盖六项。 | 不遗漏长期回顾、分享与家长反馈。 |
| “只已下课能记” vs 撤回可改 | 新规则:580、582 | 撤回是已下课课次的编辑子状态，并非被禁止的第四种上课时间状态。 | 不把撤回后的修改误锁死；家长仍见旧版。 |

## 6. 三方案共用场景与边界

本轮统一比较一场 **10 人、8 人到课、2 人请假** 的已下课课程。选中基本功、双唇音发音训练和故事作品，得到 **4 个不重复的能力方面 + 3 个特征方面**。具体孩子姓名、ID、素材归属和历史记录由共享场景提供，本文件不另起一套副本。

- 能力项：语音基础、整体流畅、角色呈现、节奏语气。每位到课孩子四项，共 32 个需表态的记录位置。
- 特征项：专注力、情绪反应、音量。每位到课孩子三项，共 24 个需表态的位置。
- 共享场景内部键：能力为 `speech / fluency / character / rhythm`，特征为 `attention / emotion / volume`。这些键不进入用户界面。
- 合计 56 个位置。这里只是供实现与验收核对的内部数量，不要求把“56 格”摆给老师。
- “还有 N 位没记”按至少一项未表态的到课孩子去重计算，不是剩余格数，不包含请假。
- 未观察算一次有效表态；无照片仍可提交；重点观察不选人合法。

共用异常覆盖：缺一人记录、缺一项记录、未选句先点人、请假孩子被点、改内容新增/移除任务、无素材、重点动作空、网络失败与重试、重复点击提交、撤回后重提、少于三次有效历史、上课中与未开始、无人签到、跨校区、接手缺监护人、家长低星与换星、分享链接过期。

在同一异常上，三方案可以用不同呈现，但业务结果必须相同。不能让某方案用预填记录或默认评价偷偷减少工作量。

## 7. 验证声明

本文件完成的是规则整理和专家设计裁决。它没有证明任何方案更快、首次使用更容易，也没有证明老师已在三分钟内完成。结构推荐、真实可操作性、自动化断言、人工计时和用户理解度属于不同证据，必须分别记录；未执行的检查只能标为待验证。
